# 07 · 接口设计与规范

> 所有 HTTP 接口经网关暴露：`http://<gateway>/api/{svc}/**`；服务间 Feign 直连（服务发现，不经网关）。

## 1. REST 规范

| 项 | 约定 |
|---|---|
| 风格 | 资源名词复数 + 动作子资源；业务动作用 `POST`（银行交易多为动作型接口） |
| 方法语义 | `GET` 查询（幂等）、`POST` 创建/动作、`PUT` 全量更新、`DELETE` 删除（仅管理端，软删） |
| 路径 | `/api/core/accounts`、`/api/core/accounts/{acctNo}/freeze` |
| 参数 | 查询分页 `pageNum`(默认1) / `pageSize`(默认20, ≤200)；时间范围 `beginDate/endDate`(yyyy-MM-dd) |
| 金额 | 请求/响应一律**整数字符串或整数（分）**；前端负责格式化 |
| 字段命名 | camelCase；枚举值大写下划线（`PAY_SUCCESS`） |
| 版本 | URL 不带版本号（培训系统单版本）；重大不兼容走新路径 |
| 文档 | springdoc：`/api/{svc}/swagger-ui.html`、`/api/{svc}/v3/api-docs` |
| Content-Type | `application/json;charset=UTF-8` |

## 2. 统一响应结构

```json
{
  "code": 0,
  "message": "success",
  "data": { },
  "traceId": "6b8f9c1a2d3e4f5a",
  "timestamp": 1789100000000
}
```

- `code=0` 成功；非 0 为错误码（见 §4），`message` 为**可直接展示给用户**的中文文案。
- HTTP 状态恒为 200（业务错误在 body），仅以下例外：网关层 `401`（未认证）、`403`（已认证无权限）、`429`（限流）、`503`（下游不可用）。
- `traceId` 与 Zipkin 链路一致，前端在错误提示中附带，便于排查。
- 分页 `data` 结构：

```json
{ "list": [ ], "total": 0, "pageNum": 1, "pageSize": 20 }
```

## 3. 通用请求头

| Header | 必填 | 说明 |
|---|---|---|
| `Authorization: Bearer <jwt>` | 登录后 | 网关校验 + 服务内解析 |
| `X-Request-No` | 资金类 POST | 幂等号（也可在 body 字段 `requestNo`，二者取一） |
| `X-Channel` | 渠道生成 | COUNTER / EBANK / ADMIN / OPENAPI |
| `traceparent` | 自动 | W3C Tracing（前端 axios 自动注入链路，网关生成根 trace） |

## 4. 错误码总表

分段：`0` 成功 · `1000~1999` 通用 · `2000~2999` UAM · `3000~3999` CORE · `4000~4999` WEALTH · `5000~5999` COUNTER · `6000~6999` EBANK · `7000~7999` GATEWAY。（业务语义详见各业务文档的异常章节，此处为全量汇总与通用段定义。）

### 通用段

| 码 | 含义 | HTTP |
|---|---|---|
| 0 | 成功 | 200 |
| 1001 | 参数校验失败（message 带字段明细） | 200 |
| 1002 | JSON 解析失败 | 200 |
| 1003 | 未认证（无 token/过期） | 401 |
| 1004 | 重复请求（幂等防抖中） | 200 |
| 1005 | 记录不存在 | 200 |
| 1999 | 系统内部错误（兜底） | 200 |

### 网关段

| 码 | 含义 |
|---|---|
| 7001 | Token 无效（签名/格式） |
| 7002 | Token 已登出（黑名单） |
| 7003 | 触发限流 |
| 7004 | 路由不存在 |
| 7005 | 下游服务不可用 |

> UAM/CORE/WEALTH/COUNTER/EBANK 段全表见 03 §10、04 §9、05 §5。下游错误码在渠道层**原样透传**（不二次包装），保证排障时错误源可追溯。

## 5. 幂等设计

| 层 | 机制 |
|---|---|
| 前端 | 提交即禁用按钮 + 生成 `requestNo`（uuid v4）随单提交；失败可原号重试 |
| 渠道 | Redis `idempotent:pre:{requestNo}` 防抖（10 分钟），DB 申请单/流水表 `request_no` 唯一索引兜底 |
| 核心/理财 | `request_no` 唯一索引；冲突时校验报文摘要一致→返回原结果（`duplicated=true`）；不一致→`3004` 幂等冲突 |
| 批量 | `(batch_type, batch_date)` 唯一 + 明细级业务键唯一（存单号/持仓+日期） |

幂等响应示例：

```json
{ "code": 0, "message": "success", "data": { "duplicated": true, "txnNo": "TX2026...", "status": "SUCCESS" } }
```

## 7. 服务间 Feign 接口（内部，airbank-api 契约）

| Client | 方法 | 说明 |
|---|---|---|
| UamClient | `getCustomer(id)`、`createCustomer(dto)`、`verifyUser(userId)`、`getUserByLoginName` | 客户与用户校验 |
| CoreClient | `postTxn(TxnCmd)` 统一记账、`openAccount(cmd)`、`freeze/unfreeze`、`getAccount(acctNo)`、`listTxns(query)`、`glBalance(date)` | 账务核心能力，全部幂等或只读 |
| WealthClient | `subscribe(cmd)`、`redeem(cmd)`、`getOrder(orderNo)`、`listProducts()`、`positionsOf(customerId)` | 理财受理与查询 |

- Feign 统一错误解码：下游非 0 code 抛 `BizException(code, message)`，渠道层原样回传前端。
- 查询类 Client 配置 fallback（Sentinel/Resilience4j 二选一，默认 Sentinel），返回降级码 `7005`。
