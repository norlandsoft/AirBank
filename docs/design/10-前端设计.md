# 10 · 前端设计

> 两个独立 React 应用（ADR-6）：`airbank-counter-web`（柜面工作台）与 `airbank-ebank-web`（网银门户）。
> 技术栈统一：React 18 + TypeScript + Vite 5 + Ant Design 5 + zustand + react-router 6 + axios + dayjs + echarts（图表）。

## 1. 工程结构（两应用同构）

```text
airbank-counter-web/
├── index.html
├── vite.config.ts            # dev proxy /api → localhost:8080；msw 插件
├── src/
│   ├── main.tsx / App.tsx    # 路由入口 + AntD ConfigProvider(主题) + 错误边界
│   ├── theme/token.ts        # 品牌主题 token
│   ├── api/                  # 模块化 API 封装（login.ts, account.ts...）
│   │   └── http.ts           # axios 实例：token 注入、traceparent、统一错误处理(code≠0 → message + 401 跳登录)
│   ├── stores/               # zustand：auth(token/user/menus)、shift(签到态/尾箱)
│   ├── layouts/
│   │   ├── WorkbenchLayout.tsx   # 柜面：ProLayout + 多 Tab 工作区
│   │   └── PortalLayout.tsx      # 网银：顶栏 + 内容
│   ├── components/           # MoneyInput(分↔元)、AccountPicker、RiskTag、StatusBadge、
│   │                         # VoucherPrint(回执打印)、CaptchaInput、OtpModal、PageContainer 封装
│   ├── pages/                # 见信息架构
│   ├── mocks/                # msw handlers（mock 开关 VITE_ENABLE_MOCK）
│   └── utils/                # money(分/元)、mask(脱敏)、dayjs、exportCsv
└── Dockerfile                # 构建 → nginx
```

## 2. 视觉与体验规范

| 项 | 规范 |
|---|---|
| 品牌色 | 柜面 `#1B4D92`（稳重蓝）；网银 `#0E8A8A`（清新青绿）；辅助成功/警示用 AntD 默认语义色 |
| 布局 | 柜面：ProLayout（侧边菜单 + 顶栏 + **页签式多业务并行工作区**）；网银：门户式顶导航 + 卡片栅格 |
| 金额展示 | 右对齐、千分位、两位小数；红色借方/绿色贷方（明细表） |
| 脱敏 | 一律后端脱敏列；卡号/证件/手机号 `*` 遮罩 |
| 空状态 | AntD Empty + 引导文案；加载骨架屏（列表/卡片） |
| 反馈 | 资金操作成功页带醒目回执卡片（单号可复制）；失败展示 `code+message+traceId` |
| 培训提示 | 环境横幅"AirBank 培训模拟环境，非真实资金"；OTP 场景提供"查看验证码"抽屉 |
| 响应式 | 柜面按 1280+ 桌面优化；网银兼容 768 平板 |
| 深色模式 | AntD `theme.darkAlgorithm` 一键切换（两应用顶栏开关） |

## 3. 柜面工作台信息架构

### 路由与页面清单

| 路由 | 页面 | 权限 | 要点 |
|---|---|---|---|
| /login | 登录 | 公开 | 工号+密码+图形验证码；登录后进签到页 |
| /shift | 签到/签退 | 登录 | 显示上日结转尾箱；签退前强制日结校验 |
| /workbench | 工作台 | 登录 | 今日笔数/金额统计卡（echarts 迷你图）、尾箱余额、待复核数、常用业务快捷入口 |
| /biz/account-open | 开户 | counter:account-open | 客户新建/选择 二步表单 → 初始存款 → 提交（≥5万自动转授权）→ 回执 |
| /biz/cash-deposit / cash-withdraw | 现金存/取款 | counter:cash | 查户（账号/卡号/证件）→ 金额 → 提交；取款校验尾箱 |
| /biz/transfer | 转账 | counter:transfer | 付款户 → 收款户 → 金额备注；大额授权 |
| /biz/time-deposit | 定期存入/支取 | counter:time | 档期选择器（利率表）、存单列表、提前支取提醒利率损失 |
| /biz/wealth | 理财代销 | counter:wealth | 产品列表 → 客户风险等级展示 → 申购/赎回 |
| /biz/account-manage | 冻结/解冻/止付/销户 | counter:account-admin | 一律需主管复核 |
| /biz/reverse | 当日冲正 | counter:reverse | 本人当日流水选择 → 反向冲正需授权 |
| /review | 待复核授权 | SUPERVISOR | 队列 + 报文明细对照（双人复核）+ 通过/驳回；支持批量通过（小额） |
| /customer | 客户查询 | counter:customer-query | 客户卡 + 名下账户/存单/理财持仓汇总 |
| /day-settle | 日结 | 登录 | 笔数金额轧账表、尾箱核对、日结单打印 |
| /vouchers | 回执查询 | 登录 | 当日/历史，打印/重打 |
| /admin/* | 机构/柜员/角色/产品/参数/批量/造数 | ADMIN/SUPERVISOR | 表格 CRUD + 危险操作二次确认 |

### 关键交互：多业务并行（真实柜面还原）

- 业务页在**页签（Tabs）**中打开，可同时受理多笔不同业务（互不阻塞）；
- 需授权的申请单提交后页签显示"待授权"角标；主管在 /review 通过后，页签自动收到执行结果（30s 轮询，P1 改 SSE）；
- 表单本地暂存（DRAFT），误关页签可恢复。

## 5. 通用组件约定

| 组件 | 说明 |
|---|---|
| `MoneyInput` | 元输入、分存储；大写金额联动（柜面凭证风格） |
| `AccountPicker` | 账号/卡号模糊搜索选择器（柜面查户核心交互），展示 户名/余额/状态 |
| `OtpModal` | OTP 发送（60s 倒计时）+ 校验 + "查看验证码"快捷入口（培训特性） |
| `VoucherPrint` | 回执打印模板（业务类型驱动），`window.print()` 局部打印，含"培训环境"水印章 |
| `AuthGuard` | 路由守卫：未登录跳登录、权限不足显示 403 页 |
| `AmountText` / `StatusBadge` / `RiskTag` | 统一金额、状态、风险展示 |

## 6. 状态管理与错误处理

- `authStore`：token、用户信息、菜单树；持久化 sessionStorage（关闭浏览器即失效，贴合柜面习惯）。
- axios 响应拦截：`code≠0` → `message.error`（附 traceId）；`401` → 清 store 跳登录；网络错误 → 统一重试提示。
- 请求防抖：资金提交按钮 loading + `requestNo` 前置生成，失败可"原单重试"。

## 7. Mock 与联调

- msw handlers 覆盖两应用全部接口（响应与 07 号文档一致），`VITE_ENABLE_MOCK=true` 时纯前端演示——便于先做界面培训、后接真实后端。
- Vite dev proxy 直连网关；前端不感知服务拆分（统一 `/api/{svc}` 前缀）。
